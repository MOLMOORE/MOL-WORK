## 改法
- 新工具 `match-calc`（category calc、icon Radio、内置纯计算）：
  - L 型：任意复数负载（'100-j50' 等复数写法由本地 parseZ 解析，含工程计数法），按 Analog Devices CN0300 口径解 ± 两组「并联+串联」元件（Ω 与 nH/pF 双输出，网络 Q）；正向不可解（G>1/Z0）自动换「并联臂在源侧」反接算法（对偶可证恒可解，仅 Re(ZL)≤0 拒绝）；
  - π 型：虚电阻 Rv 背靠背双 L 法，Q 必填并校验下限 √(R大/R小−1)，输出串 L + 两并 C 与两侧 Q；负载带虚部明确拒绝（先抵消）；
  - 单支节：Pozar 二次方程 (g−b²−g²)t²+2bt+(g−1)=0 解 d，开/短支节切换解 l，两个解都列（d/l 以 mm 与电角度给出，附 ±n·λ/2 平移说明）；波长 λ=λ0/√εr(eff)；
  - λ/4：Z1=√(Z0·RL)、|Γ|/VSWR、ρ=0.2 纹波分数带宽（Pozar 式）、λ/4 物理长度。
- 配图 `match-calc.diagram.tsx`：四种 mode 整页切换（L 型并臂+串臂 ± 两解示意、π 型 C-L-C、单支节 d/l 尺寸线按开短路端头切换、λ/4 加粗线段框），位号随 zl/z0/f/q/stubend/er 透传；纯 currentColor + 主题类，零 hex。
- 接线：registry.ts 与 diagrams/index.tsx 各 +1 项；ToolRunPage/路由零改动自动生效。计算类工具 9→10。

## 遗留 / 风险
- L/π 为窄带单频集总解；单支节与 λ/4 波长用 εr(eff) 输入近似（微带真实 εeff 与线宽相关）；π 高通变体只作说明未输出元件值；分布参数宽带匹配（多节 λ/4、渐变线）未做。
