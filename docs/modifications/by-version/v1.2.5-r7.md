# v1.2.5 第七轮 · 翻页只认小按键 · 文字模式分页重做 · 顶栏注释组统一

提交：develop（本轮）· 改动文件：`ReaderPage.tsx`、`styles/index.css`

## 需求
1. 左右翻页范围只改成小按键区域（原来整条 14% 宽的透明带太容易误触）。
2. 顶栏注释一族图标统一风格（图3：一个裸图标夹在三个带框按键中间）。
3. 文字模式：① 单页 / 双页显示不全、邻页露一条字、改不了字号、选不中文字、顶栏出现两个缩放组；② 点「连续」后顶栏丢掉大部分功能，且选中正文既不能高亮也不能注释；③ 拖过页面边界后翻不动（全挤在一页），切回书页也翻不动；④ 深色模式白纸刺眼。

## 根因
- **邻页露字**：可见窗口拿纸宽当尺寸（`sheetW = 正文宽 + 2×44`），而栏距只有 26 —— 邻栏的起点落在窗口内 18px，每页左右都会留一条别人的字。这是几何问题，与栏数测量无关。
- **翻不动（1 页）**：上一版把「量出来的栏数」回写进 `column-count` 与容器宽度，形成 布局→测量→再布局 的反馈环；再加上纸可以被拖到 1900×2600，一张纸就装下了整篇正文 → 页数 = 1。
- **书页也翻不动**：`pageCount` 是三种模式共用的状态，文字页量出的 1 会留在切回书页之后（PDF 页数只在载入时写一次）。
- **切「连续」丢功能**：顶栏整块挂在 `hasPages` 三元里，连续文字模式 `hasPages = false` → 布局切换按键（含「连续」自己）与圈注一族全消失，切过去就切不回来。
- **缩放组出现两份**：`hasPages` 分支里一份书页缩放，`mode === 'text'` 又一份文字缩放，分页文字模式两个条件同时成立。
- **选不中文字**：`onPanDown` 无条件起拖（只判 hasPages），而 `fitScale` 在文字模式仍按 PDF 页面算 → `canPan` 常为真 → 左键被平移吃掉；且 `is-panning` 会给纸面加 `user-select: none`。
- **深色刺眼**：`.tx-sheet { background: #fff }` 写死，加上 `.reader-text pre` 给整篇正文套了代码块的深底 + 内边距。

## 改法
- 热区 → 按键：`.mw-pagezone` 由「整列 14% 宽透明带」改为 38×66 的圆角按键（左右各 10px，常驻半透明、悬停点亮），能点到的就是看得见的那颗。
- 顶栏：`{hasPages ? 一坨 : 一坨}` 拆成逐项条件 —— 页码（hasPages）、布局（书页与文字都给）、动效与滚轮（hasPages）、字号（`mode === 'text'` 分页与连续都要）、缩放（三种模式共用一份，百分比按键按模式决定复位什么）、适宽适页与旋转（只书页）。注释一族改成 `.mw-toolgroup` + `ToolButton`（图标 + 文字，点亮走主色），圈画用 `CircleDashed`、旁注用 `StickyNote`。
- 分页重做（`TextBook`）：容器固定 **一栏宽**（`column-width: colW` + `column-count: auto` + `column-fill: auto` + `overflow: visible`），排不下的正文自己长成新的一栏 → 栏数只量一次（`usedColumnCount`）用来报页数，**不再回写布局**，反馈环消失；`is-measuring` 一并删掉。裁切窗口 `clipW = 正文宽 + 2×TX_BLEED(8)`、`.tx-zoom` 的 `left = PAD_X - 8`、流的 `left = 8` → 邻栏必然被切掉。纸尺寸封顶一屏（`txLimit`），`fitScale` 在文字模式恒为 1（纸的显示尺寸 = 排版尺寸）。
- 页数交还：新增 effect —— `mode` 回到 pages 且 PDF 在就把 `pdf.pageCount` 写回去。
- 选词优先：`onPanDown` 加 `if (!canPan) return` 与「起拖点在 `.tx-flow` 里就让给选词」；双页切换时把偶数页对齐回奇数页（一张纸两页，别把第 1 页挤到第二张）。
- 连续模式补齐：抽出 `useTextSelection` + `SelectionBar`，`TextStage` 也挂行内标记（`applyTextRanges`，`colW: 0` = 只画不定位）、选中浮条与点标记的就地气泡（`NotePopover` 复用，坐标按滚动容器量）。`addHighlight` / `annotateRange` 在无页时存 `page = 0`，标签写「正文」而不是「第 0 页」。
- 主题：`.tx-sheet` 走 `hsl(var(--card))` + 主题描边；`pre.reader-plain` 去掉深底 / 内边距 / 横向滚动 / 圆角。`showInk` 现在也过滤正文里的荧光（`ranges` → `showInk ? ranges : []`）。

## 参考与核验
- EPUB 阅读器的横向分页做法（Readium / epub.js：`column-width` + `column-fill: auto` + 定高，溢出横向滚动 / 平移）—— 用它替掉「column-count 回写」。
- Playwright 取证：`work/patch/txbook.html` + `txbook.mjs`、`txbook2.mjs` 复刻应用内几何（PAD 44 / GAP 26 / BLEED 8 / CSS zoom 0.85~2 / 单双页 / 小数栏宽），逐页扫 13~58 页：内容恒落在 [PAD_X, PAD_X+正文宽]，邻栏不再进入窗口；colH 300→1200 页数 58→14、colW 320→1200 页数 52→13，证明「承载文字量跟着边界变」。
- `txpage3.html/mjs` 顺带证明 `scrollWidth` 会**多算** 1~4 栏（8 vs 7、13 vs 9），所以页数只能量最后一个块的右沿，不能用 scrollWidth。

## 遗留
- 侧栏「页面 / 本页」缩略图在文字模式仍隐藏（要每栏重画一遍）。
- 亚像素：`applyTextRanges` 与 `usedColumnCount` 都用 `floor()` 判栏，缩放为小数时正好压在栏分界上的标记可能被算到邻栏（取证里 `leak` 样本全是这种 ±1 归栏误差，不是真的露字）。
- 「连续」模式没有页号，行内标记存 `page = 0`，切到分页时它靠落点显示、但侧栏标签写「正文」。
- 拖动纸边时整篇正文重排，超长文档会掉帧。
- 「连续」文字模式下顶栏只有「注释」，圈画 / 旁注 / 圈注仍按「有没有页」收起 —— 但连续模式现在能涂荧光了，所以那一档暂时没法用开关隐藏荧光（只能从侧栏注释列表删）。下轮把 `ToolButton` 的显示条件从 `inkPages` 拆成「有页才给圈注 / 旁注，文字模式就给圈画」三条。
- 文字模式仍走「书页 / 文字」两个按键，Word 类默认落在文字；排版模式（网页 / EPUB）仍不分页。
- 页数只在「排版相关的量」变化时重算；如果正文字体是异步加载的 webfont（现在没有，全是系统字体 + 内置 Inter 的拉丁子集），首次量出的页数可能偏小。真要稳，下一次给量页数 effect 加一个 `document.fonts.ready` 的 tick。
