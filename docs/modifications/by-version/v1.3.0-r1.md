# v1.3.0 第一轮 · 外部依赖应用内下载

## 需求
- 软件安装后，让用户自行选择并下载工具集需要的外部依赖。
- 便携依赖下载后自动配置，LibreOffice 与 pdf2docx 保留可理解的人工步骤。

## 根因
- 原设置页和工具页只显示安装命令，用户仍需浏览器、winget/pip 和 PATH 相关知识。

## 改法
- 新增主进程下载服务与流式下载 IO，单任务下载，支持取消。
- FFmpeg、yt-dlp、Pandoc、Playwright Chromium 下载/解压后自动进入现有依赖探测链路，安装包与便携程序使用可获得的 SHA-256 校验。
- LibreOffice 下载官方 MSI；pdf2docx 打开 PyPI 安装说明。
- 设置页和工具页共用 `DependencyManager`，提供勾选、推荐下载、进度、速度、失败原因和打开结果。
- 新增 `app:get-dependency-downloads`、`app:download-dependency`、`app:cancel-dependency-download`、`app:open-external` 和 `event:dependency-download`。

## 验证
- `npm run check-deps` 通过。
- 主进程与渲染层 TypeScript 检查均为 0 错。
- `npm run build` 与 `npm run dist` 通过，生成 `PersonalWorkstation-Setup-1.3.0.exe`。
- `Desktop\testarea` 打包版启动，依赖管理界面加载 6 项状态。
- 打包版真实下载 yt-dlp：23,575,744 字节，返回完成状态。
- `npm run check-tools`：六项依赖均可用。

## 遗留
- Playwright Chromium 需要较大下载量，本轮未重复执行完整浏览器下载。
- LibreOffice 安装包下载后仍需用户运行安装程序。
- pdf2docx 需要用户准备 Python 环境。
