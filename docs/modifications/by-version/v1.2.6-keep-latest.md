- 位置：`AGENTS.md` 第 2 节白名单与发版流程、`README.md` 目录结构与 release 句、本记录、`docs-index`。

- 遗留：以后每次发版删旧版时，exe + .blockmap + latest.yml + win-unpacked 一起换成新版；旧版 win-unpacked 无保留价值（可从 git tag 重建源码环境），一律删。
