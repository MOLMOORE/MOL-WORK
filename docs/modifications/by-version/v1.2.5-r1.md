## 翻页动效
- 根因：动效挂在「单页」上，双页时两页各自散开、中缝互盖；`preserve-3d` 让 z-index 失效，两张纸在 3D 里穿插 → 翻到一半跳层（闪）；目标页画布还没画好就开始动 → 先白纸后蹦内容。
- 改法：动效改挂图层 `.mw-layer-in/out`（双页 = 一整张纸整体移动）；**先画再动**（`pageCanvas` 预取 + `peekCanvas` 同帧贴缓存）；去掉 preserve-3d，只留 perspective；翻书只转到接近侧立并同步淡出（不越 90° 不露纸背）；回翻走物理方向（`is-reverse`）；动画期间 `.reader-page-area.is-turning{overflow:hidden}`。
- 位置：`ReaderPage.tsx` `turning/step/resetPage/pageRef/shownRef`；`styles/index.css` `.mw-book*`、`@keyframes mw-slide-* / mw-cover-* / mw-book-*`。
- 遗留：排版模式（iframe）不套翻页图层，只平滑滚动，重挂 iframe 会白屏。

## 侧边点击 / 到头提示
- 改法：热区 `.mw-pagezone` 上 `onDoubleClick stopPropagation` + `canZoneFlip`（放大、可拖动、连续、圈注模式下收起）；`step()` 到头时 `showHint(已到最后一页 / 已在第一页)`。

## 页面对比 / 页面提取
