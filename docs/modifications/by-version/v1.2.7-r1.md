## 2026-10-10 · v1.2.7（第 1 轮）
- 需求：① 默认主题的配色只保留图里的 5 种（素白简约 / 极简黑白 / 宣纸暖白 / 靛青 / 苔原），其余全删；② 全应用提示语句继续改，只描述某处功能的作用，不写无用说明与思考过程。
- 根因：v1.2.6 第 3 轮只砍了 palette 组的后 5 条，`style`（观感风格）8 条与「配色 / 观感」两层分组还在，设置页仍是 13 张卡；文案里也还留着设计动机句（「皮肤会重排界面结构，不只换颜色」「两者都与深浅色互不影响」）、复述按钮文字的 `description`、营销尾句与工具说明里的引擎名。
- 改法：
  1. **配色下架**：`THEME_PRESETS` 删 8 条 style 记录与 `group` 字段，`ThemeGroup` / `THEME_GROUP_META` / `themePresetsOf()` 一并删除，`ThemePreset` 联合收到 5 个成员；`index.css` 第二节「风格主题」242 行整段删；`SettingsPage` 的 `ThemePicker` 取消分组渲染并合并 `ThemeGrid`，直接出 5 张卡，两行分组小标题与底部说明句删掉。8 款皮肤（`data-skin`）与深浅色正交关系不变。
  2. **旧值兜底**：`applyTheme` 用 `THEME_PRESETS.some(...)` 判定，设置里存着已下架配色时写 `minimal`，顺手清掉上一轮「要用户再点一次才对齐」的遗留。
  3. **文案第二轮**：按互不重叠的三个写入集并行做（`components/**` 16 文件、`pages/**`+`main/tools/runners/**` 14 文件、`shared`+`SettingsPage` 主线自留），每处替换都断言唯一命中；判定口径沿用上轮四条（只答能做什么 / 输入什么格式 / 会有什么后果，一句能说清不写两句，简单控件不配提示，不看这句会不会做错事）。
- 位置：`src/shared/constants.ts`、`src/shared/types/domain.ts`、`src/renderer/src/styles/index.css` 第一节、`src/renderer/src/stores/appStore.ts#applyTheme`、`src/renderer/src/pages/SettingsPage.tsx#ThemePicker`；文案另及 `components/**`、`pages/{ReaderPage,NotesPage,ToolsPage,TasksPage,StatsPage,DashboardPage,PomodoroPage}.tsx`、`main/tools/runners/*.runner.ts`。
- 参考：无新增外部依赖，本轮不引入任何第三方实现。
