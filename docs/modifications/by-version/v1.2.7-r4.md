# v1.2.7 第 4 轮 · 工具改为独立运行页（2026-10-11）

## 需求
- 所有工具运行时都进入新页面（原为工具集右侧抽屉）。

## 拆分
- 路由 / 工具页 / 新页面 / store 强耦合、写入集重叠，主线单点完成，不拆子 agent。

## 改法
- 新建 `src/renderer/src/pages/ToolRunPage.tsx`：useParams 取 toolId，manifest 从 toolStore.tools 查找（列表为空先 load()，查无给空态 + 返回）；内容自原 ToolDetailDrawer 移植：停用警告、依赖缺失安装指引、ToolRunnerForm + ToolDiagram、重置 / 执行工具、最近一次执行结果（含打开文件 / 在文件夹中显示）、该工具最近 12 条运行记录；payload 随 manifestId 变化重置。
- 路由：App.tsx 在 AppLayout 内注册 `/tools/:toolId`（侧栏 NavLink 默认前缀匹配，/tools 仍高亮）。
- 入口改造：ToolsPage 卡片点击 / Enter / 执行键 / 已注册工具清单 / 运行记录行共 6 处由 select(id) 改 navigate('/tools/' + id)；GlobalSearch 工具命中由 navigate('/tools', { state })（无人消费的死路径）改为直跳。
- 清理：toolStore 删除 selectedId / select（含 remove() 内引用）；删除 components/tool/ToolDetailDrawer.tsx。

## 验证
- 两端 tsc 0 错（整合期修掉 App.tsx 锚点截断一处）；npm run build 三端通过。
- npm run dist 一次成功（Setup-1.2.7.exe 101,804,341 B + blockmap + win-unpacked 重建）；@electron/asar 回读 app.asar 渲染层 bundle，确认「返回工具集」「没找到这个工具」「该工具已被停用，启用后才能执行」等运行页字符串已进安装包。

## 遗留 / 风险
- 运行页表单值不持久化，返回再进即重置（与抽屉原行为一致）。
- 停留在运行页时工具被移除 → 显示空态，不自动跳走。
- 本轮并入 v1.2.7（未发布）；仍待用户手动验收后才合并推送与上传 Release。
