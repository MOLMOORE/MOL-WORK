# v1.2.7 第 10 轮 · 转换工具支持拖入与多文件批量转换（2026-10-16）

## 需求
- 各种转换工具（图片 / 音频 / 视频 / 文档）支持把文件直接拖进运行页，并支持一次多个文件批量转换。

## 参考
- Electron 32 起 `File.path` 已移除：拖入文件取绝对路径只能由 preload 暴露 `webUtils.getPathForFile`（本项目 `window.nativeFiles.pathForFile` 早已存在，笔记页导入在用，直接复用）。
- 批量不改各 runner 契约：在运行页对同一 payload 逐文件循环调用现有 `toolStore.run`，每个文件仍是一条真实运行记录（历史/统计照常）。

## 改法
- 契约：`ToolManifest.supportsBatch?`（四个转换 runner 置 true，`listToolManifests` 展开自动透传）；新 IPC `app:pick-files`（多选文件对话框，三处同步：ipc.ts#pickFileList / preload / app.ipc.ts）。
- `ToolRunnerForm`：新 props `batchField`/`onBatchFiles`；源文件字段旁加「批量选择文件」键（Layers 图标），多选结果回调给页面。
- `ToolRunPage`：表单卡外套拖放层（dragover 虚线高亮 outline-dashed；单文件且队列空 → 填 sourcePath；多文件 → 并入队列去重）；新增「批量转换队列」卡：每行 状态图标（Circle/Spinner/CheckCircle2/XCircle）+ 文件名 + 失败原因/产物路径 + 打开键，顶部 清空/开始批量转换 + 完成计数；startBatch 校验（排除源字段的必填项）后按队列逐个 run，pending 与 fail 都会重试，结束汇总 toast；批量运行中表单与执行键禁用。
- 中途修一处自造类名笔误（hidden-outline → outline-transparent）。

## 位置
- `src/shared/types/{domain,ipc}.ts`、`src/preload/index.ts`、`src/main/ipc/app.ipc.ts`、四个 runner、`ToolRunnerForm.tsx`、`ToolRunPage.tsx`。

## 验证
- 两端 tsc 0 错 + build；产出 CSS 断言 outline-dashed/offset-4/transparent 均在；`npm run dist` 后 asar 回读 6 项全中（pick-files 对话框、supportsBatch×4、preload 通道、队列/拖放/多选键文案）。
- 未跑 CDP 拖拽回归（L2 不需要，拖放事件路径与笔记页导入同款已验证机制）；待用户装包目检：拖 1 个文件、拖 3 个文件、多选键、失败重试。

## 遗留 / 风险
- 队列按当前表单参数逐个执行：中途改参数只影响下一轮未跑项（fail 项重试也用新参数），不做每文件锁参。
- 拖入文件夹会被 pathForFile 拒为空串静默忽略；无进度百分比（单个大文件转换中仅转圈）。
- 本轮并入 v1.2.7（未发布）；合并推送与 Release 仍待用户手动验收。
