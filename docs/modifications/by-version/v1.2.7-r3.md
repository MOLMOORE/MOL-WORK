## 改法要点
- 任务行由单 button 重构为 div.group（主体 button 兼筛选 / 勾选，兄弟 Trash2 删除键），避免 button 嵌套；多选态 primary、删除 danger，与 v1.2.6 资料卡片同一套视觉。
- 删除语义：任务软删进任务回收站，notes.task_id 不动 → 笔记保留在「全部笔记」，任务恢复后归属还在；删中当前筛选时 taskFilter 重置 null。
- 配图：纯内联 SVG 组件按 toolId 分发，随 payload（mode / topo / kind / topology / sections / fromUnit）联动；规范 schematic 符号 + 与表单一致的位号 + 图下结构名与公式；颜色全走主题令牌（currentColor + text-* 类），无 hex、无新依赖。
- filter-sim 九种拓扑与 buildNetlist 逐节点核对；filter-calc 的 lc 模式三缩略图高亮当前 topo。
