# v1.2.5 第 2 轮（2026-09-22 · commit 66ffb95）

需求（3 项）：排序加正序/倒序；对比页被顶部遮挡 + 改整页可自由拖动 + 单页放大后可拖着看；doc/TXT 支持换字体与放大。

- 遮挡根因：对比浮层挂在阅读页内部的绝对定位层里，被顶部工具条与皮肤层叠上下文压住。
- 改法：`createPortal(..., document.body)` + `fixed inset-0 z-[70]`，画布尺寸改测真实盒子（`ResizeObserver`），不再拿 window 内部尺寸猜。
- 整页工作台：`compareSlots()`（1-3 横排 / 4 田字格）、每卡独立 `zoom/panX/panY`、`ladder()` 1.15 阶梯重画 + CSS 补差、`budgetScale()` 12M 像素预算。
- 文字视图（当时的做法）：原版式文档加「书页 / 文字」切换 + PDF 现抽文字层 —— **第 4 轮已推翻重做**（见 by-version/v1.2.5-r4.md）。
- 纯文本换字体没生效的根因：Tailwind preflight 把 `pre` 钉成等宽字体，盖掉阅读器设置 → `pre.reader-plain{font-family:inherit;font-size:inherit}`。
