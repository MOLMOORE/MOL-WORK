# v1.2.6 第 1 轮（2026-10-09）· 笔记快速删除 + 回收站 / 番茄钟二次美化

## 需求
1. 笔记页（图示「资料」标签的卡片）新增各个资料 / 笔记 / 卡片模块的**快速删除模式**，同样要有弹窗二次确认，并配**回收站**。
2. 参考市面上的番茄钟软件，对番茄钟页面做**二次美化**（重点是页面美观与美术设计）。
3. 全部改动先进 `develop`，版本号 v1.2.6，打包给用户手动验收；验收通过后才合并推送（含 release）。

## 根因 / 为什么原来做不到
- 资料删除原先在 `note.service.deleteNote()` 里一步到位：`dropReviewForNote` + `DELETE FROM notes` + `removeNoteLibrary`，
  书库渲染件（`<userData>/library/<noteId>/`）当场就没了，事后无从恢复；复习条目也被直接删掉，恢复不了进度。
- 番茄钟页的番茄是 130 行内联 SVG，`defs` 里的渐变 id 是写死的字符串；页面本身只有数字输入框和一段文字说明，
  缺少阶段感与节奏感（对比 Pomotroid / Pomofocus 这类产品，差在「整块页面随阶段换色 + 本轮进度可视化」）。

## 改法
### 一、回收站（与任务回收站同一套手法）
- 数据库 v9：`notes.deleted_at TEXT` + `idx_notes_deleted`（软删除，与 `tasks.deleted_at` 对齐）。
- 删除语义改成「进回收站」：`trashNote()` 只写 `deleted_at`，并从搜索索引里摘掉；
  **彻底删除**才走原来的 `removeNote()` + `removeNoteLibrary()`（`purgeNote()`）。
- 复习计划不删，改**挂起**：`suspendReviewForNote()` 把 `status` 从 `active` 改成 `suspended`（`ReviewStatus` 本来就有这一档），
  恢复时 `resumeReviewForNote()` 改回 `active` —— 阶段、间隔、ease 全部原样保留，比删了重建诚实。
- 列表口径统一：`listNotes` / `noteCountForTask` / `tasks.note_count` 全部加 `deleted_at IS NULL`；
  `syncSearch` 遇到已软删的直接 `removeEntity`（`rebuildSearchIndex` 因此也不会把回收站的东西搜出来）。
- 过期清理：`listExpiredDeletedNoteIds(days)` 只出 id，真正的清理放在服务层 `purgeExpiredNotes()`，
  这样才能连书库目录与复习计划一起清掉；`startRecycleBinCleaner()` 现在同时清任务与资料。
- 渲染层：`noteStore` 加 `deleted` / `loadDeleted` / `removeNotes` / `restoreNote` / `purgeNote`；
  NotesPage 加 `selectMode`（点卡片勾选、全选当前标签、跨标签累积、批量二次确认）与「回收站」入口，
  新组件 `components/note/NoteRecycleBinModal.tsx` 与任务回收站同一套视觉与保留时长设置（`settings.recycleBinDays`）。
- IPC 新增 5 个通道，按规矩三处同步：`shared/types/ipc.ts`、`preload/index.ts`、`main/ipc/note.ipc.ts`。

### 二、番茄钟美化
- 视觉组件拆到 `components/pomodoro/`：`PomoStage.tsx`（阶段条 + 番茄 + 进度点 + 控制键）、`PomoPanels.tsx`（参数步进器 + 节奏带 + 今日热力带）。
- 阶段色只留一个变量 `--pomo-h`（专注 8 / 短休息 152 / 长休息 190），光晕、分段控件、主按键、进度点、面板强调色全部由它派生；
  面板在舞台之外，所以 CSS 里一律写 `var(--pomo-h, 8)` 兜底。
- 番茄「长熟」：`bodyStopsFor(phase, progress)` 在 **HSL** 空间按色相插值（起点是半熟的橙，不是青绿）。
- 进度环加十二刻度 + 渐变弧 + 端点脉冲；`useId()` 给每个实例一套 `defs` id。
- 新能力：点阶段条 `switchPhase()` 直接切阶段；空格 开始/暂停、R 重置（输入框与统计弹窗里不抢按键）。
- 新增「今日节奏」栅格条目（`api.stats.daily(today)` 的 24 格小时柱），「使用说明」压成「节奏建议」。

## 遗留
- 回收站与任务回收站是两个弹窗、两处列表（保留时长共用一个设置项）。要做成统一的「回收站」页再说。
- 彻底删除一条资料时不会动 `focus_sessions.note_id`（与 v1.2.5 之前的行为一致），统计里的历史专注分钟数会留下悬空引用；
  任务 purge 时 `DELETE FROM notes WHERE task_id = ?` 同样不清书库目录 —— 都是既有问题，本版本没扩大。
- 快速删除模式下不做「撤销」toast，只能去回收站捞。
- 番茄钟的 `phase` / `completedFocus` 仍不持久化，重启回到专注第 0 个（与历史行为一致）。
