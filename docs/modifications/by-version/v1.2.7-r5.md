# v1.2.7 第 5 轮 · 工具运行页双栏版式（2026-10-11）

## 需求
- 用户反馈：工具运行界面留白过多，优化页面显示。

## 根因
- 运行页（第 4 轮新建）沿用旧抽屉的窄单列：外层 max-w-3xl（768px）居中，而外壳内容区上限 1500px，宽屏下两侧各留 350px+ 空白；表单字段单列纵排、配图嵌在表单卡底部，纵向也松。

## 改法
- 版式重排（纯渲染层，逻辑不动）：
  - 容器去掉 max-w-3xl，用满外壳内容区宽度；
  - 页头合并：返回键、工具图标/名称/#id/分类依赖行/描述、状态徽章收进一张卡（原两行三块），停用时描述仍完整可见；
  - xl（≥1280px）起双栏 grid `xl:grid-cols-[minmax(0,1fr)_400px]`：左栏 = 停用/依赖缺失提示 + 表单卡（重置/执行收尾）+ 最近一次执行结果；右栏 = ToolDiagram 电路配图 + 该工具运行记录。窄于 xl 自动叠为单列（表单→结果→配图→历史）；
  - 配图 SVG 全部 viewBox + w-full，随右栏 400px 自适应缩放（第 3 轮已如此，无需改 diagram 模块）；
  - 结果预览 pre 由 max-h-56 提到 max-h-80，用足左栏高度。
- ToolRunnerForm：字段栅格由单列改 `grid-cols-1 md:grid-cols-2`，textarea / path / checkbox 三类加 `md:col-span-2` 占满整行；该组件仅 ToolRunPage 使用，无其他消费方。

## 位置
- `src/renderer/src/pages/ToolRunPage.tsx`（`const meta` 起的渲染尾部整段替换）；`src/renderer/src/components/tool/ToolRunnerForm.tsx`（栅格与三处 col-span）。

- 非计算工具右栏只有历史卡，配图位空白（ToolDiagram 返回 null，不留占位框）。
