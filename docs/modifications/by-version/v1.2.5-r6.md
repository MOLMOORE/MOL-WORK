# v1.2.5 第六轮 · 文字模式分页 + 选中批注 + 对比顶栏点击

对应提交：develop 上的「v1.2.5（第六轮）」。功能线：`reader-text-view` / `reader-annotation` / `reader-compare`。

## 需求
1. 对比界面顶栏「重排」按钮范围不准，鼠标在上面按下有时识别不到。
2. 文字模式：【1】也预设一张纸，用户可自主改边界、文字随边界重排，并且拥有书页那套功能（单页 / 双页 / 连续 + 五种翻页动效）；【2】可选中正文涂荧光笔，并且同样有注释功能，多一种「选中文字 → 在旁边标注」。

## 先查的参考（AGENTS.md 第 5 节）
- **Readium EPUB3 Navigator Design Dilemmas**：流式阅读器的分页推荐用 CSS multi-column（本仓库的排版模式已有 epub.js 先例）——确定「多栏 = 页」这条路是主流做法，而不是自己按块切高度。
- **denisdefreyne「Horizontally scrolling multi-column layout」**+ MDN column-width：只给 `column-width` 时浏览器会把栏**拉伸填满**容器，栏宽不精确 → 必须同时给 `column-count` 与 `width = n*栏宽 + (n-1)*栏间距`。
- **Electron 自定义标题栏 / Chromium 拖拽区域**：`-webkit-app-region: drag` 的区域是整窗命中测试算出来的，盖在上面的浮层不声明 no-drag 就收不到点击（社区大量「modal 顶部按钮点不动」的同型问题）。
- 动手前用 Playwright 量了 DOM 行为（见「验证」），两条关键结论：① `column-count` 给少了 Chromium 会**自己往外长栏**（scrollWidth 超出容器），给多了留空栏；② `zoom` 下 `getBoundingClientRect` 差值要除以倍率才是排版像素。

## 根因
1. **「重排」点不动**：`.cmp-shell` 是 `fixed inset-0`，顶栏落在窗口最上面那 34px —— 正好是自绘标题栏 `.titlebar-drag` 的 drag 区域。右端的关闭键之所以正常，是因为它落在 `.titlebar-actions`（no-drag）挖掉的洞里；「重排 / 叠放 / 挑页」在 drag 区里，按下被当成移动窗口，偶尔没位移才漏出 click。
2. **文字模式没有页**：`TextStage` 是整篇 `overflow:auto` 的长条，`mode === 'text'` 在十几处判据里被当成「没有页」写死（进度、页码、热区、滚轮、平移、批注页号全是 0）。
3. **栏数收敛不了**：第一版按「最后一个块的**左沿**落在第几栏」判栏数，正好压在栏分界上的块会因亚像素误差在 8/9 之间来回弹（Playwright 实测 6 步不收敛）。

## 改法
- **no-drag**：新增 `.cmp-shell, .mw-overlay { -webkit-app-region: no-drag }`，`ReaderOverlay` 根节点补 `mw-overlay` 类。
- **文字分页 `.tx-sheet`**：新组件 `TextBook` —— 一张纸里放一个多栏正文流（`.tx-zoom` 负责裁切与整页放大，`.tx-flow` 用 `column-count` + 算死的容器宽度排栏），第 k 页 = 把正文流 `translateX(-(k-1)*(栏宽+栏间距))`。双页就是一张纸两栏，与书页的 `page / page+1` 语义一致。
  - 栏数：`usedColumnCount()` 量最后一个块的**右沿**（往回让半个字），`useLayoutEffect` 里迭代校正，超过 4 次仍弹就取大值收尾（宁多一页空白不少一页内容）。
  - 边界：纸的右 / 下 / 右下角三个 `.tx-grip` 拖，尺寸存 `workstation.reader.txpage.v1`；没拖过就按舞台自适应（单页最宽 980、双页 1500、高 = 舞台 - 76）。
  - 正文 `useMemo` 只认 `text`：翻页、缩放、拖边界都复用同一棵 DOM，不会每翻一页重解析 Markdown。
- **判据打通**：新增 `pagedText`（文字模式且布局不是连续）与 `hasPages`，把进度落库、页码显示、左右热区、滚轮翻页、左键平移、书签 / 注释的 `page`、`canPan`、`stepZoom` 全部从 `mode === 'text'` 换成 `hasPages`。
- **批注层共用**：把 `PdfPageView` 里那 240 行批注代码抽成 `sheetNotes()`（纯函数：这一张纸上有哪几条批注、编号顺序）+ `PageInkLayer`（圈画 SVG、编号圆点、页顶按键、边上旁注、就地气泡、圈注手势），书页与文字页都调它 —— 文字页的「页」是栏，所以每栏叠一层 `.tx-col`。
- **行内标记**：`note_marks.kind` 加 `'highlight'`（该列是无 CHECK 的 TEXT，不用迁移）；`region` 复用存 `{kind:'range',start,end}`，偏移量是**渲染后正文**的第几个字，所以换字体、改边界、重排都不跑位。`applyTextRanges()` 在 `useLayoutEffect` 里先把上一轮的 `<mark>` 拆干净 + `normalize()`，再按偏移量把区间里的每个文字节点各套一层 `<mark>`（`box-decoration-break: clone` 让跨行跨栏都带满底色）；偏移量对不上原文时退回按引文 `indexOf` 再找一次。
- **选中浮条**：`pointerup` 后用 `Range.toString()` 量出选区在正文里的起止（元素级容器也能算准），浮出「涂荧光 / 写旁注」小条；旁注走 `MarkComposer`（新增 `ranged` 文案），落库后气泡贴着这段文字展开。
- 侧栏「注释」列表带上荧光标记（不然涂错了没地方取消），「仅书签」的页面集合改成只认 bookmark / star。

## 验证
- Playwright 最小 DOM（`work/patch/txpage.mjs`、`txpage2.mjs`、`txhl.mjs`）：
  - 只给 `column-width` 时栏宽会被拉伸（10 栏 5452px 里每栏仍是 520，但 n 给大就留空栏）→ 必须 `column-count` + 算死宽度；
  - `column-count` 给少会自己长栏：问 1 栏实得 10 栏，`scrollWidth` 与最后一个块都能看出来；
  - 修完判据后 380~900px 共 14 种纸宽**都是一步收敛**（左沿判据时 520 宽会 8↔9 来回弹）；
  - 荧光标记：跨块选区偏移量 253–384 与引文一致；故意给错偏移量的条目靠引文找回原位；连套两轮后 `textContent` 一字不差（幂等，不会吞字或重字）；平移到第 3 页后标记整段落在纸内；
  - `zoom: 1.6` 下 rect 差 / 1.6 正好等于排版像素。
- L0：`npx tsc --noEmit -p tsconfig.web.json` 0 错；`npm run build` 通过；`npm run dist` 出包后回读 asar 断言关键串存在。
- **没做** GUI 端到端（按 AGENTS.md 第 4 节留给用户手测）。

## 遗留 / 风险
1. 侧栏「页面」缩略图在文字模式下仍然隐藏（缩略图要把每栏重画一遍，代价大）；「本页」同理。
2. 文字模式下老数据里 `page = 0` 的注释 / 书签不会出现在任何一页上，只能在侧栏看到并删除。
3. 荧光标记是「渲染后正文的第几个字」：在连续模式里用文本框改过正文后，偏移量可能整体错位，此时靠引文兜底重定位；引文也被改过的标记会画不出来（数据还在，删得掉）。
4. 边界拖拽会触发整篇重排，超长文档（几十万字符）拖动时可能掉帧；缩放只放大纸面不重排，不受影响。
5. 文字页的圈注坐标归一化到「栏」，改边界导致重排后，圈会跟着那一页的相对位置走（与书页改纸张大小同理）。
6. 排版模式（网页 / EPUB）仍然只有整篇 iframe 缩放，没有分页。
