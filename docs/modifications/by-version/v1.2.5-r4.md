## 本轮改动
### 1. 阅读方式按格式分两类（对应需求 ④）
- 根因（这次是硬 bug）：`textBody` 只在 `info.viewMode === 'text'` 时才用 `info.text`；而抽文字层的 effect 又用
  `info.text.trim().length > 80` 当「不用抽」的 guard。Word 家族正好两个条件都命中 → 不抽、也不给正文，
  `pdfText` 永远是空串，于是永远显示占位句「正在准备文字视图…」。这不是慢，是逻辑死锁。
- 改法：删掉整篇现抽文字层这套（`pdfText` / `pdfTextBusy` / 抽取 effect），文字视图直接读库里正文；
  新增共享常量 `TEXTUAL_DOC_FORMATS`（DOC/DOCX/RTF/WPS/ODT），`prefersTextView()` 在渲染层派生：
  命中就默认 `textView = true`（打开即文字视图，可切回书页核对原版式）；PDF / PPT / Excel 不再出现「文字」选项。
- 为什么在渲染层派生而不改主进程：`note.service.ts#readNoteDoc()` 只要看到 PDF 渲染件就回 `viewMode: 'pages'`，
  改它要么动库、要么让老资料行为突变；渲染层派生零迁移，老资料立刻生效。
- 位置：`src/shared/constants.ts`（TEXTUAL_DOC_FORMATS）、`ReaderPage.tsx`（prefersTextView / canTextView / mode / textBody）、
  `NotesPage.tsx`（isTextualDoc / viewModeLabel —— 列表标签与摘要也跟着说「文字」）。

### 2. 圈注形状 + 就地气泡 + 页顶快捷按键（对应 ①②③）
- 形状：`InkShape = free | rect | ellipse | polygon`，region 存 `{ kind, points }`；矩形/圆圈只存对角两点，
  `inkOutline()` 画时展开（圆圈取 36 段折线，旋转 90/180/270 靠既有的 pageToDisplay 换算，不特判）。
  老数据没有 kind → 读成 free，兼容第三轮已存的圈。
- 多边形交互：单击逐点落点，点回起点 14px 内或按 Enter 闭合成形，Esc 作废这一笔（window capture 监听，抢在退全屏之前）。
- 气泡：`NotePopover` 定位用 `displayBox()` 求这块圈画的外接框，贴右边 12px；右边放不下就翻到左边；
  整页旁注钉纸顶右侧。`.mw-page.has-rail{overflow:visible}` 继续负责不被纸裁掉。
- 页顶按键：`NoteQuickBar` 在纸内上方一排 chip（实心编号=圈注、空心=旁注），点同一个收起；点纸面空白 / Esc 收起。
- 旁注更明显：卡片 `border-left: 3px primary` + 投影 + 12px 字号，边栏加虚线导轨（参考 Hypothesis / Zotero 的页边批注栏做法：
  批注贴在天头侧栏、与正文有明确引线，而不是堆在文末）。
- 取舍：侧栏那一列现在只放整页旁注，圈注一律走气泡 —— 因为用户明确说「不要显示在页面下方」。

### 3. 页面对比（对应 ⑤）
- 层级不能用是真 bug：`order` 按 z 降序排（index 0 = 最上面），`shiftZ` 却换 `order[index + step]`，
  于是「上移一层」在最顶上那张找不到邻居（点了没反应）、在下面的那张反而换到底下 —— 看起来就是整块功能坏掉。
  改成 `order[index - step]`，并把编号角标做成「点一下置顶」。
- 看不全右下：上一版靠 `clampPan` 手算位移钳制，纸框一旦比画布矮（`clampCard` 限过高度），被裁掉的那段永远拖不到。
  这次换模型：内容层用 CSS `zoom`（会真的撑开布局尺寸），纸框 `overflow:auto` 自己出滚动条，
  `panX/panY` 语义变成滚动位置；`clampScroll` 只锁 [0, 内容-框]，四个角一定能滚到。
  放大时保持指针那一点不动：`newScroll = (oldScroll + k) * ratio - k`，k 是光标到纸框左上角的距离。
- 拉大纸框的 `.cmp-grip` 从纸框里挪到卡片外层（滚动容器里的绝对定位会跟着内容跑）。
- 顺手：拖动起点落在滚动条那一条上时不抢事件（`offsetX > clientWidth` 判断），原生滚动条还能拖。

## 遗留 / 下轮注意
- Word 类在文字视图里不给「编辑」按钮（改的是抽取正文，避免被当成改原文件）；用户若要能编辑正文再说。
- 圆圈是 36 段折线，导出/打印场景没有矢量圆弧（目前没有这个需求）。
- 对比页仍是「书页类（PDF）才能用」；文字类资料没有页画布，不参与对比。
- 批注气泡跟着纸缩放定位，缩到极小时气泡可能压住别的内容 —— 需要时可改成 portal 到舞台层。
