# v1.2.5 第十轮（2026-09-24）— 预览像本页 · 状态条一行 · 旁注不压页

## 需求（用户 3 条）
1. 「文字」模式时的文字页预览还和本页有区别，要求几乎等于本页的缩小版。
2. 阅读页面底下的提示（尤其快捷键）字太多太繁杂，要更简洁，不要塞解释。
3. 旁注的显示又会侵入页面内影响显示（截图：整宽的旁注卡片压在下一页正文上），要更合理。

## 根因
1. 缩略图只画「正文那一块」（colW × colH），纸的四边留白与裁切窗口的起点 / 宽高都没照抄 → 预览是贴边的一栏字，本页是有白边的一张纸。
2. footer 把每条解释都摊在明面上（10 多条 span），开侧栏挤成两行还读不完。
3. `.mw-note-rail.is-below` 是绝对定位、不占排版；连续滚动页间距只有 32px，卡片 100~170px 直接盖住下一页正文（绝对定位后代只扩可滚动区、不推文档流）。

## 改法
1. `TextPageThumb` 改画整张纸：`.tx-sheet.txp-sheet`（colW+2TX_PAD_X × colH+2TX_PAD_Y，`transform: scale(ratio)` + `transform-origin: top left`），里面 `.tx-zoom` / `.tx-flow` 的 left/top/width/height 与 TextBook 的 buildSheet 逐值相同；`LazyMount` 占位高跟着改。CSS 里 `.txp-zoom` → `.txp-sheet`。
2. footer 只留「第 N / M 页」+ 一行短按键（翻页 / 下页 / 缩放 / B·S·E / 1 2 3 布局 / R 旋转(书页) / Ctrl+Shift+H(文字) / 全屏），全部解释挪进 `title`；「连续阅读 · 点上方…」→「连续阅读」，「本篇已读」→「已读」。
3. `NoteRail` 用 ResizeObserver 量高 → `PageInkLayer.onRailHeight` → `PdfPageView`（`railReserve`，仅连续滚动开）在纸下面垫 `margin-bottom = 高 + 10`；文字页另加 `railDrop = TX_PAD_Y*scale + 6` 把这一列挪到纸外；`.mw-note-card` 限高 172px 内部滚动。

## 遗留 / 风险
- 预览按「单栏那一页」画；双页模式本页是一纸两栏，预览只示其中一栏（页码单位本就是栏）。
- 文字页与逐页书页的旁注列落在纸下面，纸下空间不足时要往下滚一点才看全（与纸外编号按键同一取舍）。
- 卡片限高 172px：超长批注要在卡片内滚动看，完整内容仍可在侧栏「注释」里读。
