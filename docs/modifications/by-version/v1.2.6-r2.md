# v1.2.6 第 2 轮 · 番茄钟平面化重画 + 笔记多选与逐行删除

- 版本：v1.2.6（未发布，第二轮直接并进同一条版本日志）
- 分支：`develop`（用户验收通过后才合并 main、推 GitHub 与 release）
- 提交：本轮改动与第 1 轮同属 v1.2.6，提交信息见 `git log -1`

## 需求
1. 番茄钟界面仍「不太规矩」：要求更简洁鲜明，模块之间不能有过于大的间隔，但也要保持一定间距；现在的番茄样式太丑，去网上找参考重画。
2. 笔记页：**每一行资料都要有快速删除小键**；把现在的「快速删除」键改成**多选键**，便于快速移动资料、修改归属与批量删除。

## 根因
- 番茄钟：上一版舞台是 `flex-direction: column` + 表盘 `flex: 1 1 auto`，卡片一高（h11 = 776px）剩余空间全灌给表盘，
  而表盘 SVG 又写死 `max-height: 430px`，多出来的高度变成行间空白；加上光晕 / 网点 / 浮尘三层装饰，观感就散。
  果体本身是四级贝塞尔高光 + 立体投影滤镜，塑料感强；十二刻度环与果体重叠，视觉打架。
- 笔记：删除只有「进卡片详情」或「批量模式」两条路，逐行删要点两次；`selectMode` 当初只服务删除，
  所以按钮、配色、文案全用 danger 红，无法承载「移动 / 改归属」这类中性操作。

## 改法
### 番茄钟（平面化 + 等距栅格）
- 舞台改 `display: grid; grid-template-rows: auto auto minmax(0,1fr) auto auto auto; gap: 14px`，六行分别放
  标题 / 阶段分段控件 / 表盘 / 循环点 / 控制键 / 底栏；只剩表盘那一行吃剩余空间。
- 表盘容器 `.pomo-figure` 用 grid 铺满，SVG `width/height: 100%` + 默认 `preserveAspectRatio="xMidYMid meet"` 等比居中，
  只加 `max-width/max-height: 360px` 上限。**取证时发现**：先前想用 `aspect-ratio` + 百分比高度自己算方形，
  结果 280px 的行里量到 330px 的 SVG，直接压到下一行的循环点上；改成让 SVG 吃满、交给 viewBox 缩放才稳。
- 美术：删掉 `pomo-glow` / `pomo-grain` / `pomo-motes` 三层装饰与 `feDropShadow` 立体投影、十二刻度、端点 knob 双圈；
  果体改成「径向三段渐变的哑光圆盘 + 五片对称萼叶 + 一小段竖直果茎」，萼叶整圈用 `rotate(deg - 90)` 才围绕正上对称张开
  （不减这 90 度时叶形朝 +x 生长，画出来是一撮歪向右边的草）。
- 色相仍由单一变量 `--pomo-h` 派生；果色改由 `bodyColorsFor(phase, progress)` 直接产出 hsl 字符串
  （替换掉上一版的 `hslToHex` + 四级 `BodyStops`，SVG 的 fill / stroke 本来就吃 CSS 颜色）。
- 阶段条改三段等宽 `grid-template-columns: repeat(3, minmax(0,1fr))`；循环点从「小番茄 SVG」换成 9px 圆点。
- 页面栅格：计时卡 h11→h8、参数卡 h7→h8（两列底部对齐）、删掉「节奏建议」卡（内容已收进舞台底栏一行）、
  今日节奏 y16→y13 补到整页末尾，`storageKey` 升到 `workstation.grid.pomodoro.v5`。
- 参数卡补一排「整套预设」（标准番茄 25/5/15·4、深度工作 50/10/20·2、轻松节奏 15/3/10·4），
  开关组 `mt-auto` 贴底，消掉卡片下半截空白；面板内部零散的 `mt-4` 统一换成根容器 `gap-4`。
- 参考：Pomotroid（阶段整块换色 + 大计时字 + 细环）、Flow / Seasons（环形进度 + 极简表盘）、
  Pomofocus（分段控件 + 循环点 + 整套预设）。只借范式，未粘代码。

### 笔记（逐行删除 + 多选改归属）
- 卡片操作区在「编辑 / 阅读」前加一颗 `Trash2` 小键，直接 `setConfirmId(note.id)` 复用既有二次确认与回收站链路；
  多选模式下与小键一起隐藏，避免和勾选打架。
- 「快速删除」键改名「多选」，配色由 danger 红改 primary（红色只留给删除动作），勾选框与卡片选中态同步改主色。
- 多选操作条加三个下拉：移到任务 / 移到项目（课程）/ 换类型，各带一项「无所属…」用来清空归属；
  原生 `select` 的 value 只能是字符串，用 `'none'` 哨兵在 null 与数字之间换算，选完 `value=""` 常量自动复位。
- 数据侧新增一条 IPC `note:move-many`（三处同步：`shared/types/ipc.ts`、`preload/index.ts`、`main/ipc/note.ipc.ts`）：
  `moveNotes(ids, patch)` 只改 patch 里**出现过**的键（`'taskId' in patch` 判定，才能把「清空」的 null 传进来），
  语句带 `AND deleted_at IS NULL` 保证回收站里的条目不会被误改，改完逐条 `syncSearch`（搜索元数据里带任务 / 项目名）。
  共享类型 `NoteMovePatch` 放 `domain.ts`，store 里 `moveNotes` 改完直接 `load()` 刷新列表。

## 遗留
- 逐行删除小键与「多选」共用一个 `ConfirmDialog`，撤销 toast 仍没有（第 1 轮遗留未变）。
- `note:move-many` 不校验任务 / 项目是否存在，靠外键兜底；若以后支持从别处传 id，要在服务层先过滤。
- 换类型只改 `notes.kind`，不会动复习计划：卡片（flashcard）转成资料后仍带复习条目，与第 1 轮「挂起 / 恢复」口径一致。
- 番茄 `phase` / `completedFocus` 仍不持久化（既有问题）；整套预设只写设置，不重置正在跑的这一段。
