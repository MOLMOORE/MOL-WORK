# v1.2.9 · 本地打包与测试版替换

## 需求
- 将五个基础计算工具的代码更新打入 1.2.9 本地安装包。
- 按新的测试目录规则，把 1.2.9 解包版放到普通 Desktop 目录并通过真实启动烟测。

## 根因
- 上一轮只完成源码与构建验证，`testarea` 仍是 1.2.8。
- 直接在项目 `release/win-unpacked` 运行会受到工作区 ACL 影响，因此必须在普通 Desktop 目录验证。

## 改法
- `package.json`、`package-lock.json`、README 产物名和双写 CHANGELOG 更新到 1.2.9。
- 执行一次 `npm run dist`，生成 1.2.9 安装包、blockmap、`latest.yml` 与解包版。
- 先复制到 Desktop staging，使用隔离 userData 真实启动 8 秒确认主窗口显示。
- 旧 1.2.8 测试目录、`release/win-unpacked`、1.2.8 安装包和 blockmap 移入回收站。
