## 改法
- 新增工具（category calc、requires []、builtin，接入 ToolRunPage 双栏与配图分发，无需改路由/页面）：
  - `rect-calc` 整流滤波与电源电容：半波 / 中心抽头 / 桥式三拓扑；正算 Vdc·纹波 Vr(pp)·Vr(rms)·γ·PIV·二极管平均电流，或按目标纹波反算 C 并就近 E6 标准值回算实际纹波；教材标准近似（纹波按三角波）。
  - `timer-555` 555 定时器速算：无稳态 RA/RB/C 正算 f/D/tH/tL，f+C(±目标占空比) 反算并 E24 就近复算；单稳态 t=1.1RC 正反算；基本接法占空比恒 >50% 在 notes 说明。
  - `trace-calc` PCB 走线宽度速算：IPC-2221 经验式 I=k·ΔT^0.44·A^0.725（外层 k=0.048 / 内层 0.024），铜厚 0.5~3 oz 分档，选填长度算电阻/压降/损耗。
  - `wave-rms` 交流波形有效值换算：正弦/方波/三角/锯齿 Vpk·Vpp·Vrms·整流平均值互算 + 波形因数/峰值因数 + 万用表按正弦刻度的坑。
- 四张配图随表单联动切图（三拓扑全电路 / 无稳与单稳两接法含输出波形框 / 外层内层截面按铜厚分档 / 两周期波形标 Vpk·Vrms·Vavg 三线），纯内联 SVG、currentColor + 主题令牌、零 hex，接入 `diagrams/index.tsx` 分发。
- 接线仅两处：`registry.ts` import+注册 4 项；`diagrams/index.tsx` import+分发 4 项。

## 遗留 / 风险
- 公式口径：整流/555/wave 为教材标准近似（三角纹波、NE555 数据手册式），trace 为 IPC-2221 经验式——都不是场求解级精度，notes 已写明适用边界与复核建议。
- wave-rms 的整流平均值 Vavg 对非正弦按“全波整流后平均”定义，万用表真有效值档读数不受影响，平均值刻度档需按 notes 换算。
- 555 反算占空比 <50% 需 RB 并联二极管的变体接法未建模（notes 说明）；整流反算按满载连续模式，轻载/断续模式纹波会大于估算。
