## 需求
1. 文字模式：① 单页 / 双页下还是选不中正文；② 连续（滚动）里能选中，但「注释 / 高亮」那条浮框经常离选中区域一大截 —— 要准、要显眼，高亮还要能挑颜色；③ 缩回侧栏再拉出来会看到书页那套「页面」，要求文字模式保留自己的页面栏（含书签），字体或纸边一变缩略图跟着变，又不许和书页的「页面」混。
2. 查找：能涂色的文本就高亮涂出来；页面（PDF）不好涂的，就像注释那样把命中那一行圈出来。
3. 文字格式下页面下方那截字符排版出错。
4. 本轮收尾：整体清一遍历轮留下的死代码，给项目减臃肿（不许碰有用的东西）。

## 根因
- **分页文字选不中字**：`.tx-col`（每一栏上盖着的批注层）在 CSS 里**根本没有规则**，默认 `pointer-events: auto`，绝对定位铺满整栏，于是鼠标按下永远落在这层空 div 上，正文一个字也框不住。Playwright `work/patch/txsel.html` 直接量出来：有这层时 `elementFromPoint` 返回 `DIV.txcol`、模拟拖选得到 **0 个字符**；给它加 `pointer-events:none` 后同一次拖选选出 **123 个字符**。书页不受影响，是因为那里本来就没有需要选中的字。
- **浮条飘走**：`useTextSelection.pick` 算的是 `rect.top - hostRect.top`（两个客户端矩形相减 = 相对视口），而 `TextStage` 的宿主就是那个滚动容器 —— 内容滚多远，浮条就相对内容飘多远。同一个文件里 `NotePopover` 早就补了 `+ host.scrollTop`，只有浮条漏了。另外锚点取 `range.getClientRects()[0]`，跨元素选区的第一个片段经常是个零宽空盒子，本身就不可信。
- **纸下方那一截排错**：栏底在 `TX_PAD_Y + colH`，而 `.tx-zoom` 的裁切底边是整张纸高（`sheet.height`，含 46px 下边距）—— 于是「栏里放不下、又不许断栏」的整块会一路画进下边距。两种东西会变成不可断栏的整块：`.reader-text pre { overflow-x: auto }`（代码块成了滚动容器）与比一页还高的 `<img>`。取证：把 1200px 高的图塞进 632px 的栏，`flow.scrollHeight` 变成 1209，多出来的 568px 就压在纸的下边距上。
- **侧栏为什么会露书页**：`mode === 'text'` 时标签里 `页面` 被过滤掉，但顶栏「展开侧栏」写死 `setPanel('thumbs')` —— 收起再展开，面板停在被过滤掉的 tab 上，而 `tab === 'thumbs' && pdf` 仍然成立（Word 类资料也有 PDF 渲染件），于是把书页的原版式页码画了出来。

## 改法
- **让开鼠标**：`.tx-col{pointer-events:none}`，再把真正要点的几样单独放回来（`.mw-ink path` / `.mw-ink-dot` / `.mw-note-quick` / `.mw-note-rail` / `.mw-note-pop` / `.mw-ink-catch`）。圈注模式的采集层照旧铺满，不影响画圈。
- **浮条**：锚点改成「丢掉零宽片段后，取最上面那一行的左右沿」，坐标一律补上 `host.scrollLeft / scrollTop`（宿主不是滚动容器时这俩就是 0，书页与分页文字那边行为不变）；上面放不下就自动翻到选区下面（`data-place` + CSS 小三角）。样式换成实底卡片 + 主色描边 + 外发光，按键从光图标变成「图标 + 文字」，中间夹一排荧光色板。
- **高亮颜色**：不加迁移，直接用 `note_marks.color`（建表时就有这一列，一直空着）。五支笔（黄 / 绿 / 青 / 粉 / 紫）画在 `mark.tx-hl[data-hl]`，用固定 rgba 而不是主题令牌 —— 荧光笔本来就该跟纸面底色拉开，深浅两套都压得住；当前用哪支记在 `workstation.reader.hlcolor.v1`。同一段再点同色 = 取消，点别的色 = 改色而不是叠一条。
- **文字页缩略图（`TextPageThumb` + `LazyMount`）**：拿和纸上**完全一样**的 colW / colH / 字号 / 栏距再排一棵正文树，外面套 `transform: scale()` 等比缩小 —— transform 不参与排版，所以分页结果与纸上逐字一致；改字体、改字号、拖纸边都会立刻重排（几何由 `TextBook#onLayout` 报回 `txGeom`）。一屏十几份整篇正文会卡死，故用 IntersectionObserver 只在滚到附近时才真排，远的先留同尺寸占位框。文字模式下这一栏标签叫**「文字页」**，底部再写一句「与书页原版式页码不是一套」；「全部页面 / 仅书签」与书签角标跟书页共用；连续文字模式仍把它收起，顶栏展开按键改成落在当前阅读方式真正存在的那一栏。
- **查找**：`runFind` 从侧栏提到 `ReaderPage`，命中清单三份共用（侧栏列表 / 文字涂色 / 书页画圈）。
  - 文字（分页与连续）：`applyTextFind` 把每一处命中套上 `mark.tx-find`（当前这处再描一圈），顺手量出每处落在第几栏报回去当页码。偏移口径与荧光标记一致（渲染后的正文），换字体改字号不跑位。坑：**必须从后往前套** `<mark>`，先改前面的文字节点会把后面的偏移全弄错。
  - 书页：新增 `pdf.ts#pageFindHits`，逐页 `getTextContent()`，按 y 分行、把命中跨的几个片段合成矩形，归一化到**页面自身坐标**（用 `page.view` 那个裁剪框；pdf.js 2.16 没有 `page.width/height`），交给 `InkStrokes variant='find'` 画成虚线椭圆 —— 与批注同一套几何，缩放 / 旋转自动跟。扫描版没有文字层就圈不出来，提示里写清楚。
  - 排版模式（网页 / EPUB）仍走 iframe 自带查找。侧栏多了「上一处 / 下一处」与命中列表，点查找或 Ctrl+F 自动聚焦输入框；改了词还没回车时提示会说明列表是上一次的结果。
- **纸底那一截**：`.tx-zoom` 底边收到 `TX_PAD_Y + colH + TX_BLEED`（与左右同样的出血），越界的内容不再渗进下边距；文字页里 img/svg/video/canvas 限到一栏高（`--tx-colh` 由 `TextBook` 写进来，`object-fit: contain` 等比缩不裁内容），代码块从 `overflow-x: auto` 换成软换行 `pre-wrap + overflow-wrap: anywhere`，让它能像普通段落一样一栏一栏断。**这条限高绝不能套到 `.reader-plain` 上** —— 纯文本整篇就是那一个 `<pre>`，套了等于把全书塞进一栏。
- 顺手：`goPage` 在双页下把偶数页对齐回左页（从缩略图 / 查找列表跳偶数页时那张纸会把第二页当左页，看着像少一页）；顶栏注释工具组按 r7 遗留清单拆成三条（有页才给圈注 / 旁注，圈画连连续文字也给，因为正文荧光归它管）；侧栏目录不再拿 PDF 书签冒充文字页目录。

## 遗留
1. 「文字页」缩略图是排版预览，不是画布快照；「本页」那一栏仍是书页专属。
2. `applyTextFind` 每处最多记 600 处，超出只涂色不进列表；PDF 每页最多 3 处、全程 120 处（pdf.js 无 worker，逐页取文字很贵）。
3. 查找涂色与荧光标记共用「先拆再套」的排版 pass，两遍 `normalize()`；超长正文连点「下一处」能察觉重排耗时。
4. 亚像素老问题没变：正好压在栏分界上的标记可能被 `floor()` 判到邻栏。
5. 扫描版 PDF（无文字层）查找只能提示搜不到，不做 OCR。
6. 连续文字模式仍没有页概念，`page = 0` 的标记只能在侧栏「注释」里删。
