# v1.2.5 第九轮 · 高亮快捷键 · 「文字页」每页都有预览 · 纸可以拖得比窗口宽 · 状态条显示全 · 注释编号按键搬出纸外

提交：develop（本轮）· 改动文件：`pages/ReaderPage.tsx`、`styles/index.css`、`pages/SettingsPage.tsx`、`CHANGELOG.md`、`docs/*`

## 需求
1. 打上 / 删除高亮要有快捷键：选中文字后按一下就涂上，再按一下删掉。
2. 文字模式：① 侧栏「文字页」除了第一页，其余都没有预览；② 页面边界的**横向**改变范围要放大（现在拖不动）。
3. 文字模式底部那行「第 N / M 页 + 快捷键提示」还是显示不全，而且**只在开着侧栏时**，把侧栏关掉就好了。
4. 加过注释后挂在页面左上角的那排小圆框（编号按键）要放到本页面之外，不要压在页面里影响显示。

## 根因
- **缩略图只有第一页有预览**：`TextPageThumb` 给缩略图正文另抄了一套 CSS（`.txp-flow { overflow: hidden }`），而纸上的 `.tx-flow` 是 `overflow: visible` —— 多栏正文里第二栏起本来就画在栏框**外面**（靠外层 `.tx-zoom` 裁），自己再裁一遍就只剩第一栏；再套 `translateX(-(page-1)*(colW+gap))` 把整框平移出可视区，第 2 页往后自然一片空白。Playwright `work/patch/txp.html` 命中测过：同一份 DOM，`overflow:hidden` 时缩略图中心 `elementFromPoint` 落到 `DIV.zoom`（没有画出来），`overflow:visible` 时落到 `P`（有字）。第一页两种都一样 —— 与用户描述逐字对上。
- **横向拖不动**：`txLimit.width` 拿舞台宽当上限，`txSheet` 又用 `capW = min(980 | 1500, txLimit.width)` 把「用户拖出来的尺寸」和「没拖过时的自适应值」混在一起卡，`resizeTxSheet` 再夹一次 —— 三道夹子里外都是「一屏宽」，`TX_MAX_W = 1900` 根本到不了。
- **状态条只在开侧栏时显示不全**：底部 `<footer>` 在 `<main>` 里，侧栏是它的兄弟节点 —— 开侧栏 `main` 变窄，而 footer 是 `h-7` 单行 flex，`<span>` 的 `min-width:auto` 又压不下去，多出来的提示直接溢出被裁。顶栏在侧栏之外，所以宽度不变（这也是「关掉侧栏就好了」的原因）。
- **编号按键压住正文**：`.mw-note-quick` 写死 `top: 6px; left: 6px`，永远落在纸内左上角。

## 改法
- **高亮快捷键 `Ctrl+Shift+H`**：新增 `shortcutHighlight()` —— 现场读 `window.getSelection()`，从选区节点 `closest('.reader-text')` 找到正文根（分页纸与连续滚动都是这个类），用**和浮条完全相同**的 `rangeOffsets()` 量偏移量，所以与纸上画的、侧栏列的是同一套坐标。命中判定：某条高亮**整条落在选区内**或**整个盖住选区**都算按到，走 `note:remove-mark` 删掉（可能一次删多条）；否则调 `addHighlight(span, quote)` 涂当前笔色。接线在 `onKey` 的 Ctrl 分支里加 `case 'H'`（Shift 按出来就是大写 H），输入框内仍走原有 typing 早退。因为 `useEffect` 的依赖数组是在渲染期求值的，`addHighlight` / `shortcutHighlight` 整块**移到快捷键 effect 之前**，否则 `const` 会撞 TDZ。
- **缩略图**：不再抄第二份规则 —— 直接复用纸上的 `.tx-zoom` + `.tx-flow`（`className="tx-zoom txp-zoom"` / `"reader-text tx-flow"`），`.txp-flow` 整条 CSS 删掉，`.txp-zoom` 只留一个 `transform-origin: top left`。顺手把 `--tx-colh` 也传进去，缩略图里的图片与纸上一样限到一栏高。
- **横向范围**：`txLimit` 拆成 `autoWidth`（只给「没拖过边界时」的自适应用）与 `height`；用户拖出来的宽度只受 `TX_MAX_W` 限制并提到 **2600**（`txSheet` / `resizeTxSheet` 都改读它）。超出舞台的部分由 `.reader-page-area` 自己的 `overflow:auto` 兜住，右边缘的 `.tx-grip-w` 滚过去照样拖得着。纵向仍一屏封顶（一张纸装下整篇就没有翻页可言）。两个拖拽手柄的提示文案跟着改。
- **状态条**：`h-7` → `min-h-[1.75rem]` + `flex-wrap` + `whitespace-nowrap`（每条提示不被腰斩，排不下就换第二行），并精简掉重复的两条（「点两侧小按键翻页」「到头会提示」并进「← → 翻页」），文字模式那条补上 `Ctrl+Shift+H`。
- **编号按键搬出纸外**：`.mw-note-quick` 去掉 `top/left/right` 的纸内定位，改由组件写 `bottom: calc(100% + Npx)`（`NoteQuickBar` 新增 `lift`，`PageInkLayer` 新增 `quickLift`）：书页 `lift = 0` 就是纸上方 6px；文字页的批注层是从纸的上边距里开始的，抬 `TX_PAD_Y * scale` 才真到纸外面。同时把 `.tx-col .mw-note-quick` 从「放开命中」名单里摘掉（容器 `pointer-events:none`，按键自己带 `auto`），免得那条横跨纸宽的空容器去抢上一批注列的鼠标。
  **纸上方要有地方放**：`fitScale` 的上下留白从 44 提到 `TX_ROOM_Y = 68`（只改纵向），`txLimit.height` 同样按 68 扣，连续滚动的页间距 `gap-4 → gap-8`、顶部内边距 `py-5 → pt-10 pb-5` —— 适页时纸上方稳定留出 ~34px，按键（6 + 21px）不会被舞台裁掉。
  顺手：`.mw-note-chip-text` 加 `color: inherit; font-weight: 500`，纸外的编号按键文字在浅色皮肤下不再淡到读不出。

## 参考
- MDN / CSS Overflow：多栏容器里超出栏框的分片属于**视觉溢出**，靠外层裁切框裁；自己再 `overflow:hidden` 会把后面的栏整条吃掉。
- `Selection.getRangeAt` + `Node.closest` 定位选区宿主：与 pdf.js text-layer、hypothesis 侧「按渲染后文本偏移量存标记」同一口径（本轮沿用仓库既有的 `rangeOffsets`）。
- React：`useEffect(fn, deps)` 的依赖数组在渲染期求值 ⇒ 被引用的 `const` 必须声明在其之前。

## 遗留
1. `Ctrl+Shift+H` 只在文字模式（分页纸与连续滚动）有效：书页是画布，选不出字。删高亮时按「整条落在选区内 / 整个盖住选区」判定，只压到一半的高亮不会被误删，但也删不掉 —— 想精确删除仍用浮条点同色。
2. 编号按键搬到纸外后，**放大**（`zoom > 1`）或「适宽 / 连续」下纸顶可能贴到舞台边缘，按键会落在可视区外，需要往上滚一点才看得见（纸本身也一样被裁，不是本轮新增的问题）。
3. 纸横向放到 2600 时，单栏行长已经很宽，靠用户自己收；缩略图此时会缩成一条窄带（`ratio = 116 / colW`），仍是等比预览，不改分页口径。
4. 状态条换成可换行后，窄窗口下会占两行高度，舞台纵向少约 14px。
